# Source policy

The repository stores structured technical facts and provenance rules, not copyrighted service-manual reproductions.

## Priority
1. Physical evidence / measurements from the actual unit
2. Yamaha service documentation for the exact generation
3. Yamaha 21DE parts catalog
4. 2014 owner manual
5. Official aftermarket manufacturer documentation
6. Technical secondary sources
7. Marketplace
8. Community reports
9. Inference
